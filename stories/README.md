# Stories Directory

This directory contains individual story pages for the archive.

## Adding a New Story

1. Copy `example.html` as a template
2. Rename it to something descriptive (e.g., `jane-doe-vs-news-corp.html`)
3. Fill in the story details:
   - Replace the title
   - Add background information
   - Document the case details
   - Include the outcome
   - Discuss significance
   - Add relevant resource links
4. Update `../index.html` to add a card linking to your new story
5. Submit a pull request

## Template Structure

Each story page includes:
- **Background**: Context and circumstances leading to the lawsuit
- **The Case**: Legal proceedings and key developments
- **Outcome**: Settlement, verdict, or current status
- **Significance**: Broader implications for media/journalism/rights
- **Resources**: Links to documents, coverage, and related materials

## Style Guidelines

- Use clear, factual language
- Cite sources when possible
- Maintain consistent formatting with the template
- Keep the focus on documenting the case and its significance
